# Cantonal coats of arms

26 SVG files named by canton code (`ZH.svg` … `JU.svg`), used in the tile map, rankings and trend selector.

**Source:** Wikimedia Commons, series "Wappen … matt" (flat versions), marked public domain; metadata stripped.
They were taken over unchanged from the author's *Canton Hunter* project (`xirvik.ch/canton-hunter`).

Per-file authorship/licence details are on the respective Commons file pages. Before reusing the
files outside this project, check those pages. Cantonal coats of arms are official emblems: use them
for identification/information only, not in a way that suggests official endorsement.

Modification: a dark outline (`data-outline` path, ~1.7 % of the shield width) was added on top of each shield and the viewBox widened accordingly, so the shapes stay readable at 20-26 px on light backgrounds. Colours and charges are unchanged.
